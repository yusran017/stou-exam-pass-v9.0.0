# 🎓 STOU Exam Pass - ระบบตารางสอบและโครงสร้างหลักสูตร มสธ. (v2.0)

แอปพลิเคชันเว็บแบบ Progressive Web App (PWA) ออกแบบเฉพาะสำหรับนักศึกษามหาวิทยาลัยสุโขทัยธรรมาธิราช (มสธ.) ใช้งานง่าย ไม่รกตา โฟกัสเฉพาะสิ่งสำคัญ: **วิชาที่กำลังจะสอบ วัน-เวลาสอบ สถานที่สอบ ห้องสอบ และโครงสร้างหลักสูตร** พร้อมทำงานแบบ **Offline 100%**

---

## 🌟 คุณสมบัติเด่น (Features)

### 1. 📅 แถบตารางสอบ (หน้าหลัก)
- **Live Countdown Timer**: นับถอยหลังสู่วันสอบวิชาถัดไปแบบเรียลไทม์ (วัน : ชั่วโมง : นาที : วินาที)
- **เรียงลำดับตามวันสอบ**: วิชาที่สอบก่อนจะอยู่ด้านบนเสมอ
- **⚙️ ปุ่มฟันเฟืองแก้ไขรายละเอียดสอบ (Inline Edit)**:
  - สามารถกดไอคอน ⚙️ เพื่อแก้ไขหรือเพิ่ม **สถานที่สอบ/สนามสอบ, ห้องสอบ/อาคาร, เลขที่นั่งสอบ, และแถวสอบ** ได้ทันทีโดยตรง
  - บันทึกลงหน่วยความจำของเครื่อง (LocalStorage) ใช้งานได้แม้ปิดเบราว์เซอร์
- **แจ้งเตือนปฏิทิน**:
  - ปุ่ม **"เพิ่มลง Google Calendar"** คลิกเดียวเพิ่มนัดหมายเข้า Google Calendar
  - ปุ่ม **".ics"** ดาวน์โหลดไฟล์ปฏิทินมาตรฐานสำหรับ Apple Calendar, Outlook หรือแอปปฏิทินในมือถือ

### 2. 📚 แถบโครงสร้างหลักสูตร (Curriculum)
- **สรุปสถิติผลการเรียน**: แสดงจำนวนวิชาทั้งหมด, สอบผ่าน, จะสอบ, ไม่ผ่าน, สอบซ่อม และแถบหน่วยกิตสะสมที่ผ่านแล้ว
- **ค้นหาและกรองข้อมูล**: มีช่องค้นหารหัสวิชา/ชื่อวิชา และชิปตัวกรองสถานะ (ทั้งหมด, จะสอบ, ผ่านแล้ว, ไม่ผ่าน, ซ่อม, ยังไม่ลง)
- **เปลี่ยนสถานะวิชา (Dropdown)**:
  - 📝 จะสอบ (`will_take`)
  - ✅ สอบผ่าน (`passed`)
  - ❌ ไม่ผ่าน (`failed`)
  - 🔄 สอบซ่อม (`retake`)
  - ⏳ ยังไม่ลง (`not_taken`)
- บันทึกสถานะอัตโนมัติ

### 3. 📥 แถบนำเข้าข้อมูลและดาวน์โหลด (JSON Manager)
- **เงื่อนไขและโครงสร้างไฟล์ JSON**: อธิบายฟิลด์ที่จำเป็น (`courses`) และฟิลด์เสริม (`curriculum`, `examCenter`) อย่างชัดเจนด้วยการ์ดดีไซน์พรีเมียม
- **ดาวน์โหลดแม่แบบ JSON (Template)**: ดาวน์โหลดไฟล์ `stou-exam-template.json` เพื่อนำไปกรอกข้อมูลตารางสอบของคุณเอง
- **ส่งออกข้อมูลปัจจุบันเป็น .json**: ดาวน์โหลดข้อมูลที่คุณแก้ไขทั้งหมด (ห้องสอบ, ที่นั่ง, สถานะหลักสูตร) ออกมาเป็นไฟล์ `.json` เก็บไว้สำรองหรือย้ายเครื่องได้ตลอดเวลา
- **คัดลอก JSON แม่แบบ**: คัดลอกโครงสร้าง JSON ลงคลิปบอร์ดได้ทันทีในคลิกเดียว
- **อัปโหลดไฟล์ .json**: ลากไฟล์มาวาง (Drag & Drop) หรือแตะเพื่อเลือกไฟล์จากเครื่อง
- **ปุ่มโหลดข้อมูลตัวอย่าง มสธ.**: ทดลองใช้งานแอปได้ทันทีโดยไม่ต้องเตรียมไฟล์

### 4. 🎨 ดีไซน์และประสบการณ์ใช้งาน
- โทนสีอัตลักษณ์ มสธ. เขียวมรกต (`#065f46`) และทองอร่าม (`#f59e0b`) พร้อมพื้นหลัง Dark Mode กระจก Glassmorphism
- สลับโหมดมืด (Dark) / โหมดสว่าง (Light) ได้
- Mobile-First: แถบนำทางด้านล่าง (Bottom Dock) พอดีกับหน้าจอมือถือ ไม่ล้น ไม่เล็กเกินไป ไอคอน SVG คมชัดทุกขนาด

## 🚀 วิธีเปิดใช้งานและเผยแพร่บน GitHub Pages (ขั้นตอนแก้ไขปัญหาลิงก์เปิดไม่ได้)

### 1. ตรวจสอบโครงสร้างไฟล์บน GitHub (สำคัญที่สุด ⚠️)
ไฟล์ **`index.html`** จะต้องอยู่ที่ **Root Directory (นอกสุดของ Repository)** ไม่ควรอยู่ในโฟลเดอร์ซ้อน เช่น:
- ✅ **ถูกต้อง:** `https://github.com/<username>/<repo>/blob/main/index.html`
- ❌ **ไม่ถูกต้อง (จะทำให้เปิดเว็บไม่ติด/ขึ้น 404):** `https://github.com/<username>/<repo>/blob/main/Stou Examinaion/index.html`

> *หากเผลอลากทั้งโฟลเดอร์ขึ้นไป ให้ย้ายไฟล์ทั้งหมด (`index.html`, `sw.js`, `.nojekyll`, `manifest.json`, โฟลเดอร์ `css/`, `js/`, `data/`, `icons/`) ออกมาไว้ที่หน้าแรกของ Repository*

---

### 2. วิธีเปิดใช้งาน GitHub Pages ใน Settings
หากอัปโหลดไฟล์เสร็จแล้ว แต่ยังไม่มีลิงก์เปิดเว็บ ให้ทำตามขั้นตอนนี้:
1. เข้าไปที่หน้า Repository ของคุณบน GitHub
2. กดไปที่แท็บ **⚙️ Settings** (แถบเมนูด้านบนสุด)
3. ที่เมนูด้านซ้าย เลื่อนหาหัวข้อ **Code and automation** แล้วคลิก **Pages**
4. ในส่วน **Build and deployment**:
   - **Source**: เลือก `Deploy from a branch`
   - **Branch**: เลือก `main` (หรือ `master`)
   - **Folder**: เลือก `/ (root)`
   - กดปุ่ม **Save**
5. รอระบบ GitHub Actions ประมวลผลประมาณ **1 - 2 นาที**
6. รีเฟรชหน้า จะปรากฏกล่องข้อความสีเขียวพร้อมลิงก์เว็บไซต์ของคุณ:
   `https://<your-username>.github.io/<repository-name>/`
7. ตรวจสอบให้แน่ใจว่าได้ติ๊กเลือก **Enforce HTTPS** (เพื่อเปิดใช้งานระบบ PWA ติดตั้งแอปบนมือถือได้)

---

### 3. เปิดใช้งานแบบ Local (เปิดบนคอมพิวเตอร์หรือมือถือโดยตรง)
- ดับเบิลคลิกเปิดไฟล์ `index.html` บน Google Chrome, Microsoft Edge หรือ Safari ได้ทันทีโดยไม่ต้องพึ่งพาเซิร์ฟเวอร์
- หรือรันผ่าน Live Server / VS Code / Python SimpleHTTPServer (`python3 -m http.server 8080`)
- บนมือถือ Android หรือ iPhone สามารถกดปุ่ม **"ติดตั้งแอป"** เพื่อติดตั้งเป็นไอคอนบนหน้าจอหลัก (PWA) ใช้งานได้แม้ไม่มีอินเทอร์เน็ต (Offline 100%)
